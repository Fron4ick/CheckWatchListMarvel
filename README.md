# Marvel Timeline Board

Интерактивная карта фильмов и сериалов киновселенной Marvel в формате бесконечной доски. Основной сайт на Next.js находится в корне проекта; закрытая совместная версия на Google Apps Script находится в [`apps-script`](./apps-script/README.md).

## Возможности

- масштабирование колесом относительно точки под курсором (от 0.28× до 1.45×);
- свободное перемещение по карте;
- отметки просмотренных фильмов с локальным сохранением (`localStorage`);
- облачная синхронизация «Просмотрено» между устройствами: вход по одноразовому коду на email или через OAuth (Яндекс/Google/VK), last-write-wins слияние через `backend/`;
- кнопка «Копировать»: текст с текущим временем, Twitch-ссылку и постер фильма в буфер обмена;
- добавление, изменение размера и удаление фотографий (в Apps Script-версии);
- текстовые заметки и пользовательские фотографии с исходными пропорциями;
- прямые ссылки на страницы фильмов на SSpoisk;
- режимы «По датам выхода» и «Хронологически» (внутримировая хронология) с плавной анимацией;
- линии персонажей: цветные пути, соединяющие все проекты с участием героя; клик по линии подсвечивает путь и показывает справку о персонаже;
- многослойная цветная обводка карточек — по одному слою на главного персонажа проекта;
- легенда персонажей с быстрым выделением;
- поиск по названию, году, персонажу и внутримировому периоду;
- фильтры по группам, типу, статусу каноничности и фазам;
- встроенный редактор: замена постеров, цвета и толщина линий персонажей, участие персонажей в проектах, добавление своих проектов/персонажей, экспорт/импорт изменений одним JSON-файлом.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

Если dev-сервер уже был запущен ранее и «подвис» (белый экран, десятки `node.exe`) — сначала сделайте чистый перезапуск одной командой:

```bash
npm run dev:clean
```

Она освобождает порт 3000 (убивает все процессы-слушатели), удаляет повреждённый кэш `.next` и запускает **ровно один** dev-сервер. Никогда не запускайте `npm run dev` во втором терминале, пока первый работает: два сервера конкурируют за общую папку `.next/dev`, спавнят десятки воркеров Turbopack, исчерпывают память и падают с «белым экраном».

Облачная синхронизация включается переменной окружения `NEXT_PUBLIC_API_URL` (адрес развёрнутого backend из [`backend/`](./backend/README.md)). Без неё карта полностью работает локально, как раньше:

```bash
# Linux/macOS
NEXT_PUBLIC_API_URL=https://<функция>.functions.yandexcloud.net npm run dev
# Windows (PowerShell)
$env:NEXT_PUBLIC_API_URL="https://<функция>.functions.yandexcloud.net"; npm run dev
```

### Если снова виден белый экран

1. Дождитесь строки `✓ Ready` в терминале, затем обновите страницу жёстко: `Ctrl+F5` (или очистите данные сайта). Браузер мог закэшировать HTML от сломанной предыдущей сборки.
2. Проверьте, что в терминале нет ошибок вида `FATAL ERROR: process out of memory` / `os error 1450`. Если есть — повторите `npm run dev:clean`.
3. Проект лежит в папке Яндекс.Диска (`...\Yandex.Disk\projects\...`). Облачная синхронизация непрерывно трогает десятки тысяч файлов в `.next` и `node_modules`, что приводит к бесконечным пересборкам Turbopack, росту числа процессов `node.exe` и падению сервера. Добавьте папки `.next` и `node_modules` в исключения синхронизации Яндекс.Диска (Настройки → Синхронизация → Исключения) — это устраняет причину рецидивов навсегда.

## Структура

- `app/` — страницы Next.js (App Router);
- `components/` — компоненты карты (линии, легенда, инфо-панель, редактор, управление);
- `data/` — база данных медиапроектов и персонажей MCU (типы, фильмы, сериалы, персонажи);
- `lib/` — сборка данных доски, раскладка карточек, прокладка маршрутов линий;
- `public/posters/` — локальные постеры проектов;
- `apps-script/` — закрытая совместная версия на Google Apps Script;
- `backend/` — serverless REST API (Yandex Cloud Functions + YDB): вход по одноразовому коду, синхронизация «Просмотрено»; подробнее в [`backend/README.md`](./backend/README.md);
- `.sourcecraft/ci.yaml` — CI/CD: автоматический деплой `backend/` в Yandex Cloud Functions при пуше в `master`/`main`;
- `ТЗ_к_улучшению_проекта.md` — техническое задание и справочная база данных MCU.
